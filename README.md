# Happy New Year Prank Card

A simple New Year's greeting card that ends with a classic Rick Roll.

# How it works

When the website is opened, it immediately begins loading the video in the background. The page displays a button that says:

"To hear a special message, click here."

When the button is clicked, the preloaded video instantly begins playing.

The video is hosted on Google Drive and starts loading as soon as the page opens. Since browsers require user interaction before playing media with audio, clicking the button provides the required user gesture, allowing the video to play immediately.
